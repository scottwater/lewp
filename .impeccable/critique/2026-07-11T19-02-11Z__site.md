## Anti-Patterns Verdict

**LLM assessment: passes on concept — a director would say "made on purpose," not "AI made this."** The two-worlds system (warm paper for explaining, dark terminal objects for proving, one hand-drawn loop as the only whimsy) is a genuine committed POV, and the site avoids the modal VC-SaaS page entirely: no gradient hero, no hero metrics, no logo walls, no fabricated proof. Numbered markers appear only on the genuinely sequential 3-step process; features are hairline rows, not a card grid.

Two committed choices flirt with saturated patterns, honestly flagged:
- **The teal uppercase kicker appears above 4 of 5 landing sections plus the docs top.** DESIGN.md names it a brand system, but "an eyebrow on every section" is exactly the saturated cadence the ban list describes. This is the one place the site speaks AI's dialect.
- **The warm-cream body (#F7F4EE)** sits squarely in the 2026 cream-default band. It's shipped brand identity (identity-preservation applies) and the two-worlds concept rescues it, but combined with Geist it forms a familiar silhouette.

**Deterministic scan** (exit 2, 4 findings, both pages): `overused-font` — Geist/Geist Mono are on the AI-default typeface list (line 15, both files; factually accurate, but a committed identity choice here). `em-dash-overuse` — 10 em-dashes on index.html (accurate: all genuine prose cadence, an AI writing tell the design review missed) and "129" on docs.html (**strong false positive**: 122 are CLI `--flags` like `--json`/`--host`, only 14 real em-dashes).

## Overall Impression

A crafted, confident site whose visual system does real rhetorical work — and whose weakest moment is, unluckily, its conversion point. The before/after card is the best argument on the page; the install section is the worst. The reader PRODUCT.md describes ("will inspect an install script before piping it to bash") arrives at `curl … | bash` and finds zero reassurance, an inaccurate requirements line, and a first command (`lewp lease`) that will fail because `lewp setup` is never mentioned on the landing page. The single biggest opportunity: make the install fold as trustworthy as the docs already are.

## What's Working

1. **The before/after transformation card.** "The demo is the pitch" and "name the pain in their words" executed simultaneously — the dim localhost list on paper resolving into a dark terminal of clean https URLs with a green ✓ is the site's emotional and rhetorical peak. The two-worlds palette carries semantic meaning, not decoration.
2. **The committed two-worlds system.** Real commands with real output in every terminal, deliberately dull titlebar dots, mono reserved for machine speech. The craft itself is the trust argument, exactly as PRODUCT.md intends.
3. **Docs troubleshooting and uninstall documentation.** Sudo, the local CA, /etc/resolver, teardown, Firefox/NSS limits — all explained honestly. This is where "earn the curl|bash" actually lives; it just isn't surfaced where the curl|bash happens.

## Priority Issues

- **[P1] Landing omits `lewp setup`; the hero advertises `lewp lease`, which fails before setup runs.** A first-timer follows the page literally, installs, types `lewp lease`, and hits an error — breaking PRODUCT.md's success metric ("runs lewp setup within minutes") and belief step 4. **Fix:** make setup a visible step zero in the install sequence and/or How-it-works. **Command:** /impeccable clarify
- **[P1] "Earn the curl|bash" is not honored at the conversion point.** No note on what install.sh does, no "read the source" link, no mention that setup uses sudo, writes /etc/resolver/lewp, and trusts a local CA. The exact balk moment for this audience gets nothing; the reassurance exists one click away in docs, unlinked. **Fix:** a short trust note beside the command (what it touches, "read install.sh ↗", routes-only promise) plus links to troubleshooting/uninstall. **Command:** /impeccable clarify (copy) or /impeccable harden (trust surface)
- **[P2] WCAG AA contrast failures, contradicting the explicit AA promise.** Computed: teal #0E8C8C on paper = 3.72:1 (fails for 13–15px kickers, active nav, hero-url link); faint #9A9891 on paper = 2.63:1 (card labels, footer tag, docs contents title); before-card list #7A776F on #FBF9F3 = 3.95:1; terminal comments #6E6A62 = 3.07:1. Ink/soft-ink/faded-ink/terminal body colors all pass. **Fix:** darken teal for small-text uses (~#0A6E6E clears 4.5) or reserve teal for large/brand; bump faint metadata. **Command:** /impeccable colorize or /impeccable harden
- **[P2] The core interaction has no affordance: no copy button anywhere; docs sidebar has no scroll-spy and no grouping.** The one action the site drives (copying a command) requires manually selecting a nowrap, horizontally-scrolling line — worst on mobile. The 21-link flat TOC fails working-memory limits (only >4-option decision point on the site). **Fix:** copy buttons with copied-state feedback; group the sidebar (Setup · Commands · Reference) and add an active state. **Command:** /impeccable onboard + /impeccable layout
- **[P2] Misleading requirements line: "Requires macOS · Go 1.25+".** The primary curl path ships a prebuilt binary; Go matters only for `go install`. Reads as imprecision from a tool whose pitch is precision. **Fix:** "Requires macOS. Go 1.25+ only for the go install path." **Command:** /impeccable clarify

## Persona Red Flags

- **Jordan (first-timer):** installs, types `lewp lease` because the hero shows it, hits an error — setup never mentioned. "Lease" unglossed. Hand-selects commands. Abandons at first failure.
- **Skeptical senior dev (PRODUCT.md's explicit audience) / Riley:** wants to read install.sh before piping to bash — no link, no mention of sudo or keychain CA. The wrong Go requirement reads as imprecision. Bypasses the funnel to GitHub or bounces.
- **Casey (mobile):** layout collapses cleanly, but the hero and install commands are nowrap horizontal-scroll strips — the conversion action is the worst mobile moment, with no copy button.

## Minor Observations

- 10 genuine em-dashes in index.html marketing prose — an AI-cadence writing tell worth thinning (docs count is a false positive: CLI flags).
- Brand casing drifts: `lewp` vs `Lewp` (docs prose). Pick one rule.
- Six identical loop glyphs in the features list differentiate nothing.
- Docs h2 headings are mono — prose headings in machine voice, borderline against DESIGN.md's own Machine Voice Rule.
- `scroll-behavior: smooth` is global with no reduced-motion override; 21 anchor links animate for reduced-motion users.
- theme-color matches paper — nice mobile-chrome touch.

## Questions to Consider

2. The hero promises `lewp lease`, but the true first command is `lewp setup`. Which command should the hero actually make?
3. Would the page lose anything if only "How it works" kept its kicker?
